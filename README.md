# lol-scam-check

Statische Aufklärungsseite „Scam erkannt!“ zu Scam-Links im League-of-Legends-Chat.

- Reines HTML/CSS, **kein JavaScript**, keine Formulare, keine Cookies
- Keine externen Ressourcen, keine Analytics, kein Tracking
- Strikte Content-Security-Policy (`default-src 'none'`)
- Hosting: GitHub Pages (der Anbieter kann technisch bedingte Server-Logs führen)
